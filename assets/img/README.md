# Дарья Ситдикова — персональный фитнес-тренер в Нижнекамске

Одностраничный сайт-визитка в стиле референса: тёмный «постерный» фон, плотная
типографика Unbounded, розовый акцент, вырезанные из фона фотографии тренера,
интерактивные блоки, аккордеон, карусель отзывов и модалка записи.

**Сайт:** https://manath-iq.github.io/trener-bot-site/

---

## Стек

Без сборки и без зависимостей: чистый HTML + CSS + vanilla JS.
Стили и скрипт разбиты по модулям и разложены по папкам, шрифты (Unbounded +
Manrope, кириллица) лежат локально — сайт открывается мгновенно и не зависит от
CDN, что важно для России.

```
.
├── index.html                  разметка всех секций + SVG-спрайт иконок
├── .nojekyll                   чтобы GitHub Pages не обрабатывал файлы через Jekyll
├── assets/
│   ├── css/styles.css          дизайн-система: токены, компоненты, секции, адаптив
│   ├── js/app.js               вся интерактивность (~16 модулей, IIFE, без зависимостей)
│   ├── fonts/                  self-hosted woff2 (cyrillic + latin) + fonts.css
│   └── img/                    favicon.svg + сюда кладутся фотографии (см. ниже)
└── README.md
```

## Локальный просмотр

```bash
cd site
python3 -m http.server 8777
# открыть http://127.0.0.1:8777/
```

Открывать файл через `file://` не стоит — часть браузеров блокирует загрузку
локальных шрифтов и скриптов при таком протоколе.

## Что уже работает

- **Адаптив:** 360 / 390 / 768 / 1024 / 1280 / 1440 / 1920 — проверено, горизонтального
  скролла нет ни на одной ширине.
- **Анимации:** появление секций по скроллу (IntersectionObserver, каскад через `--i`),
  мягкий параллакс вырезанных фото, 3D-tilt по курсору, «магнитные» кнопки,
  бегущая строка, анимация кольца прогресса.
- **Переключатель «Разово / Абонемент»** — цены плавно подменяются, состояние
  хранится в `data-billing` на `<html>`.
- **Карусель отзывов** — drag мышью, свайп на тач-устройствах, стрелки, точки,
  управление с клавиатуры.
- **FAQ-аккордеон** — плавная анимация через `grid-template-rows: 0fr → 1fr`.
- **Модалка записи** — валидация полей с инлайн-ошибками, состояние загрузки,
  экран «Заявка готова», копирование готового текста в буфер и deep-link в Telegram
  с уже подставленным сообщением. Никакого бэкенда не нужно.
- **Состояния:** есть loading (спиннер в кнопке), error (подсветка поля + текст),
  empty (слоты под фото), disabled (стрелки карусели на краях).
- **Доступность:** skip-link, `aria-expanded` / `aria-checked` / `role="dialog"`,
  focus-trap в модалке, `Esc` закрывает, полное уважение `prefers-reduced-motion`.
- **Мобильный sticky-бар** с оффером и кнопкой записи (скрыт на десктопе).

## Как подставляются фотографии

В вёрстке каждая картинка — это «слот»: контейнер `[data-cutout]` с `<img>` и
аккуратным плейсхолдером под ней. Пока файла нет — показывается розовый
плейсхолдер с подписью (`Кадр 1 · daria-hero.png · рост 3/4, вырезка без фона`),
битой иконки не будет. Скрипт сам определяет загрузку и плавно проявляет фото.

**Достаточно положить PNG с нужным именем в `assets/img/` — сайт подхватит его
при следующей загрузке.** Можно добавлять по одному, ничего в коде править не надо.
В консоли браузера скрипт пишет, каких файлов ещё не хватает.

| Файл | Размер | Где используется |
|---|---|---|
| `daria-hero.png` | 1080 × 1620 (2:3) | Главный экран, справа |
| `daria-band.png` | 900 × 1200 (3:4) | Блок «С заботой и вниманием» |
| `daria-stretch.png` | 820 × 1000 (~4:5) | Секция «Частые вопросы», слева |
| `daria-avatar.png` | 400 × 400 (1:1) | Круглая аватарка в блоке «На связи» |
| `og-cover.png` | 1200 × 630 (1.91:1) | Превью ссылки в мессенджерах |

Тень под фигурой добавляет CSS (`drop-shadow`), поэтому в самой картинке тень
не нужна — иначе получится двойная.

### Если прозрачный фон не получился

Модель иногда отдаёт фигуру на подложке. Что делать:

1. Попросите в том же чате: «убери фон полностью, оставь только фигуру,
   прозрачный фон, PNG с альфа-каналом».
2. Либо сгенерируйте на идеально ровном фоне `#00FF00` или `#FFFFFF` и удалите
   фон любым инструментом (remove.bg, Photoshop, Photopea).
3. Проверьте края: у вырезанной фигуры по контуру не должно быть белого или
   зелёного ореола — иначе на тёмном фоне сайта будет видна кайма.
4. Сохраните как **PNG** (не JPG) с нужными именами из таблицы выше и положите
   в `assets/img/`.

### Чего избегать в генерациях

- Разных женщин в разных кадрах — это сразу читается как «сборная солянка».
- Запечённой тени под ногами и «студийного» серого фона.
- Любого текста и логотипов внутри картинки: вся типографика уже есть в вёрстке.
- Пересвета и пластиковой кожи — на тёмном фоне сайта это выглядит дёшево.

## Деплой

Сайт — статика, лежит в корне ветки `main` и публикуется через GitHub Pages
(Source: `Deploy from a branch` → `main` → `/ (root)`). Файл `.nojekyll` отключает
обработку через Jekyll, поэтому папка `assets/` отдаётся как есть.

Обновление:

```bash
git add -A
git commit -m "Обновление сайта"
git push
```

Pages подхватит изменения за минуту-полторы.

Все пути в проекте относительные (`assets/...`), поэтому сайт одинаково
работает и в корне домена, и в подпапке `/trener-bot-site/`, и локально.
