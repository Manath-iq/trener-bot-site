# Картинки для сайта

Пока файла нет — на его месте показывается розовый плейсхолдер с подписью,
поэтому сайт выглядит целым даже без фотографий. Достаточно положить PNG с
нужным именем в эту папку, ничего в коде менять не надо.

| Файл | Размер | Где используется |
|---|---|---|
| `daria-hero.png` | 1080 × 1620 (2:3) | Главный экран, справа |
| `daria-band.png` | 900 × 1200 (3:4) | Блок «С заботой и вниманием» |
| `daria-stretch.png` | 820 × 1000 (~4:5) | Секция «Частые вопросы», слева |
| `daria-avatar.png` | 400 × 400 (1:1) | Круглая аватарка в блоке «На связи» |
| `og-cover.png` | 1200 × 630 (1.91:1) | Превью ссылки в мессенджерах |

Требования: PNG с альфа-каналом для вырезанных фигур, без тени на полу —
тень добавляет CSS. `favicon.svg` уже готов, его менять не нужно.

**Готовые промты для генерации — в корневом [README.md](../README.md#промты-для-генерации-картинок-chatgpt-image-последняя-версия).**
